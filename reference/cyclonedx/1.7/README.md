# Pinned CycloneDX 1.7 schemas

These are unmodified schema assets downloaded from `https://cyclonedx.org/schema/` for offline, reproducible validation. `schema-lock.json` records the retrieval date and SHA-256 of every file. The upstream specification and licensing terms are maintained at `https://github.com/CycloneDX/specification`.

The validator checks every pinned digest before compiling the official root schema and its external references. The files are test/reference inputs; they are not included in the deployed browser bundle.
