# SPDX 2.3 schema

Unmodified upstream JSON Schema pinned by schema-lock.json for validating the
artifact-inventory export.

- Upstream: https://github.com/spdx/spdx-spec
- Source revision: aadf3b0b8dbbabdb4d880b0fc714255fea436ff7 (v2.3)
- SPDX specification copyright: Linux Foundation and its contributors
- License: CC-BY-3.0, https://spdx.github.io/spdx-spec/v2.3/license/

SPDX FILE-purpose packages carry measured SHA-256 identities. `filesAnalyzed`
is false because no SPDX file-level licensing scan is performed. No SPDX File
records or synthetic SHA-1 values are emitted. License and copyright information
remain NOASSERTION. DEEPBOM findings are annotations, not SPDX 3 AI-profile fields.
