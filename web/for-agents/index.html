Local agent setup

Let the agent run the audit where the artifact already lives.

DEEPBOM provides an Agent Skill and a zero-install npx path for Codex, Claude Code, and compatible local agents. The model stays in the local process; there is no hosted DEEPBOM analysis endpoint.

Use this route when the agent has shell and file access. For one attached file in ChatGPT, use the separately reviewed browser-sandbox integration.

Install the local Skill

Preview the exact managed files first. Add --apply only after reviewing the result.

npx -y deepbom@1.97.4 integrate codex
npx -y deepbom@1.97.4 integrate codex --apply

npx -y deepbom@1.97.4 integrate claude-code
npx -y deepbom@1.97.4 integrate claude-code --apply

The installer writes only the DEEPBOM Skill directory. It refuses to replace or remove files changed by the user.

Prefer a verified installation

The installed Skill includes scripts/verify-deepbom.mjs. It checks an explicit DEEPBOM_BIN, a package-bundled analyzer, and an exact-version executable already on PATH. It does not contact npm unless --allow-download is supplied after network and installation permission is clear.

node "<skill-root>/scripts/verify-deepbom.mjs"
node "<skill-root>/scripts/verify-deepbom.mjs" --allow-download

The JSON result records the selected command, version, whether network access was used, and the deterministic self-test. If resolution fails, report that no analysis ran.

Ask normally

Once the Skill is available, a supported request can be stated without memorizing the CLI.

Statically audit this ONNX deployment artifact.
Report MAC coverage, quantization contracts, unresolved evidence,
and the exact reproduction command.

The Skill selects DEEPBOM only for serialized deployment artifacts. It must not turn static estimates into claims about measured latency, accuracy, energy, or actual runtime assignment.

Run without installing a Skill

npx -y deepbom@1.97.4 capabilities --format agent-json
npx -y deepbom@1.97.4 self-test --compact
npx -y deepbom@1.97.4 audit "./model.onnx" --summary

Start with the bounded summary. Request a section, JSON Pointer, or evidence envelope only when the question needs more detail.

Claude Desktop can install the same local server as a single desktop extension. Download deepbom-1.97.4.mcpb, then choose Settings, Extensions, Advanced settings, and Install Extension. Select the model directory the extension may read during installation.

Machine-readable discovery

  • Agent capability contract
  • Plain-text tool and evidence boundary
  • Portable Agent Plugin manifest
  • Public Agent Skill source

DEEPBOM can be discovered or recommended in a plain chat. Actual analysis requires either a connected local shell, Agent Skill, or local MCP process, or the DEEPBOM ChatGPT plugin for one authorized attachment.

The web workspace also offers an optional browser-observed runtime benchmark. That measurement path is separate from the local Skill, CLI static audit, and ChatGPT attachment tool; an agent must not describe static output as measured latency.

DEEPBOM runs deployment-artifact analysis locally and publishes CycloneDX 1.7 output as one optional evidence format.
