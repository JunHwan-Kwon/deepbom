Create a report locally
python -m deepbom.optimization optimize --factory my_model:build_model --output candidate
# Open candidate/report.json here.
# Re-export PDF locally:
deepbom optimization-report candidate/report.json --format pdf --output report.pdf

The last command is the npm CLI; PDF requires the matching Python deepbom[report] installation.
