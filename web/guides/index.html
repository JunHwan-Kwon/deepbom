Reproducible inspection guides

Start with the model-file question, not the product name.

Each guide identifies what can be observed from serialized artifact bytes, gives a pinned reproduction command, and states what still requires runtime, lineage, or task evidence.

Choose the question

  • Inspect ONNX quantization without running the model
  • Inspect mixed GGUF tensor encodings and storage

Common boundary

These workflows report static artifact evidence. They do not establish measured latency, task accuracy, clinical validity, safety, regulatory compliance, or the execution provider and kernel selected at runtime.

Commands are pinned to a release; identify the analyzed artifact by SHA-256.
