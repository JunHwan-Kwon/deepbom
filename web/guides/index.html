Candidate review with external evaluations

The optional DEEPBOM Review preview packages baseline/candidate evidence, fixed criteria, and hash-bound evaluation records. Use the CLI walkthrough and the MLflow or Olive adapter instructions. Imported measurements remain external evidence; the review tool does not execute them.

Common boundary

Static inspection does not establish measured latency, task accuracy, clinical validity, safety, regulatory compliance, or the execution provider and kernel selected at runtime.

Commands are pinned to a release; identify the analyzed artifact by SHA-256.
