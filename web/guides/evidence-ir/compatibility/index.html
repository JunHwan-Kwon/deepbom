How to read mapping status
Implemented
A concrete implementation path exists; referenced checks do not mean every possible artifact is tested.
Conditional
Requires a compatible artifact, decoder, binding or supplied evidence; inspect run coverage.
Preview
A bounded adapter exposes only the listed native scope.
Proposed
A design boundary is recorded; there is no working adapter.

Field groups are a navigational crosswalk, not a complete leaf-by-leaf conversion specification. Auxiliary command schemas and runtime-specific profile fields are outside this first catalog.
